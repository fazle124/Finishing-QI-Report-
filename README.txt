====================================================================
Daily Finishing QI Report - Windows Desktop .exe রূপান্তর নির্দেশিকা
====================================================================

ফোল্ডারে থাকা ফাইলগুলো:
1. index.html       -> আপনার আসল কোড (কোনো পরিবর্তন ছাড়া)
2. main.js          -> Electron এর মূল স্ক্রিপ্ট
3. package.json     -> কনফিগারেশন ও বিল্ড স্ক্রিপ্ট
4. build.bat        -> এক ক্লিকে .exe বানানোর ফাইল
5. run_preview.bat  -> রান করে দেখার ফাইল
6. Colossus.jpeg    -> আপনার লোগো
7. Rabbi.png        -> আপনার প্রোফাইল ছবি

কমান্ড লাইনে .exe বানানোর ৩টি সহজ ধাপ:
--------------------------------------------
ধাপ ১: এই ফোল্ডারে টার্মিনাল বা CMD খুলুন।
ধাপ ২: npm install
ধাপ ৩: npm run build:win

অথবা সরাসরি "build.bat" ফাইলে ডাবল ক্লিক করুন!
বিল্ড শেষ হলে "dist-electron" ফোল্ডারে আপনার কাঙ্ক্ষিত .exe ফাইলটি পেয়ে যাবেন।
